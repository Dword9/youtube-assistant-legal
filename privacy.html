YouTube Assistant - Privacy Policy

Last updated: 13 November 2026.

YouTube Assistant is a personal, single-user tool. It is used only by its owner to manage the owner's own YouTube channel. It is not offered to the public and has no other users.

Data accessed

With the owner's explicit consent through Google sign-in, the tool uses the YouTube Data API and YouTube Analytics API to read the owner's channel information, videos, comments and analytics, and, only when the owner asks, to upload videos, update video metadata and reply to comments.

Storage and use

The OAuth refresh token is stored encrypted on the owner's own computer. Channel data is processed locally on that computer. It is used only to perform the actions the owner requests.

Sharing

We do not sell, share, publish or transfer Google user data to any third party. The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the locally stored token also ends access.
